2. **MO-ATTACH-010 (b) 연결 가이드**: 케어센스 에어 흐름인데 STEP 문구가 리브레 가이드(리브레 앱 설치…)를 그대로 복사한 상태. 가이드 이미지도 없음
3. **MO-ATTACH-010 (a) 센서 선택**: 디자인엔 케어센스 에어만 있음. 리브레 가이드/계정 연동 화면은 정책서에 있어서 선택지에 같이 넣음 — 리브레 지원 여부 확인

5. **MO-GLYCEMIC-010**: 기능설명 없음 (와이어프레임만). 예측 등급(B, +16 mg/dL) 산식, 2시간 후 문구, 삭제/수정 동작 정의 필요
6. **COM-POP-11 일일카드**: 피그마가 '일일카드 임시 작업' 상태
